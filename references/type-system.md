# 文字与版式体系（2026-11-10 由 Apple 视频案例的逐项修订归一，脚本照此执行）

## 字体与字重

- 中文：Noto Sans SC 两档——正文 Regular 400、标题与标签 SemiBold 600。不用细字重，不全粗。
- 英文：Inter 三档——Regular 400（原话、展品）、Bold 700（关键词、时间码、旋律刻度）、**Light 300 只用于小标题**：区段标题后的英文副题、气泡徽章的英文、声音区维度副标。
- 例外：主标题站酷快乐体；拍立得手写句 Patrick Hand。
- 字重必须渲图验证（可变字体实例化可能返回错档，名为 Bold 的默认实例可能是 Thin）。

## 字号阶梯（不许散值）

- 正面：30 主标题 / 14 区段标题 / 11 维度名 / 10 小标题与展品题 / **9.5 正文（全篇统一，行距 13）** / 9 标签 / 8.5 注文与副标。
- 背面：25 页标题 / 13 指标大数字 / 11 维度名 / 10 区段标题 / 9.5 引言 / 8.5 表格正文与方法注 / 7.5 表头。

## 正面组件规则

- **维度条（内容区、声音区同一个组件）**：维度名 11 SemiBold + 印章 + 副标 8.5 + 小红花 0.9，全篇六个维度一个摆法，维度条领起本区（在展品之上）。
- **印章**：跟在维度名之后，间距 48pt；章字 9.5 SemiBold；倾斜 ±2° 交替；**颜色按花数**：4–5 朵绿 #2E9E4F、3 朵黄 #D9930D、1–2 朵红 #C73E1D，不许一律一色。
- **维度副标**：格式 =「考试名 · 该考试的具体量规」，点名真实量规（Starters · 主题词表 / 结构清单 / can-do 陈述；IELTS · Pronunciation / Fluency and Coherence 用官方全称）。禁止把一个考试的维度名拼另一个考试的名。
- **总评组件（两区同款）**：橙描边小章「总评」8.5 + SemiBold 一句 9.5，置区段标题正下方，写本区结论，不写过程。结论的**定性必须明说**（如降调写「稳稳落地」，不写中性的「尾巴往下落」——没说清好坏的观察会被家长读成毛病）。
- **声音图（声音区总领图，定式）**：一条时间轴叠**两层实测**——上层整段波形（左标「声音大小」）、下层基频线（左标「声音高低」），三处主要停顿以浅橙带贯穿两层、秒数标在带下。它与三栏的分工：大小层管流利（说满程度与停顿位置）、高低层管语调（起伏与句尾落地）；**发音不上图**（词级对错归发音栏文字）。基频线**不单独出现**（单独一条线家长读不懂、只会问「这是什么」），也不给它加导游箭头或贴纸式标注——需要箭头解释的元素就是没站住。
- **区段标题右端注文**：只写对标出处（如「参照剑桥 Starters 量规」「对标 IELTS 口语标准」），不写方法说明。
- **气泡**：
  - 时间标用**起止区间**（00:04–00:26），三段首尾相接、合计全长；不用单点起始时间，也不用纯时长（三段时长相加不等于总时长，段间停顿不属于任何气泡）。
  - 高度 = 39 + 行数 × 12.5；原话首行在顶边下 24pt，行距 12.5。
  - 波形 + 点评行**锚在原话末行之下 14pt**（不锚气泡底边）；点评文字与波形带**光学居中**对齐（文字基线 = 行中线 −3，波形基线 = 行中线 −5）。
  - 点评用气泡自身的深色（与波形、时间码同色）：「点评」SemiBold + 正文 Regular；与孩子原话的黑色分开。
  - 章节徽章坐在气泡顶边、**大半落进气泡内**（顶边下 9.5pt 起），不许骑在接缝上挡住上一个气泡的点评行；气泡间距 7pt。
  - 红色虚线下划线只标每个练习词的**首次出现**。
  - 贴纸（tag）默认无；只有案例数据自带时才画，不许模板自带贴纸文案。
- **拍立得**：双模式——视频案例用真实抽帧照片（题注如实写「视频里截的这一帧」）；纯音频案例按孩子原话画肖像（题注「照他原话画的「我」」）。题注必须与素材来源一致。
- **老师的话**：整段（手写句 + 行动 pill + 评语段）**只有拿到真实教师评语时才出现**；没有就整段省略，不许生成文本冒充。出现时上方模块相应收紧（脚本 TEACHER 分支已处理间距）。
- **回家一起玩**：定式三栏——勾选框 + 游戏名 10 SemiBold + 说明 9.5 两行，无面板、无底色、无卡片组（圆角粉彩卡片组是明确雷区，尾部不要再加设计）。
- 红色只用于有依据的高光（如孩子自创的句子），无来由的红色强调不许出现。

## 背面构成（正式标准文件，不是解读页、不是示例）

- 只有四件，按序：页眉（左 kicker + 标题；右只写日期与「依据录音：…」，**不写**「第 2 页 / 报告背面 / 配套使用 / v1」等过程性用语）→ 定位段 → 六维对标表 → 本次录音的技术指标 → 方法注收尾。**无页脚**。
- **成长阶段的定级标准不印在背面**：阶段只在正面成长卡呈现；定级标准存于 `rubric.md` 内部执行（且只在一个量规框架内分档，见 rubric）。
- 区段标题用名词式（「维度对标表」「本次录音的技术指标」），不用问句式。
- 表格线语法全页统一：顶线 1.6、表头下 0.7、行间发线 0.45、底线 1.6；每个表都要有表头行。
- 证据栏写**结果**，不写核对过程（不写「逐句核对」「三套系统交叉核对定位到」这类过程语；系统数与分歧结论直接写成结果）。
- 方法注用家长话：内容看孩子实际所说的话、声音直接测量录音本身；不写「量规锚定」式行话，不自白技术短板。
- 标准类文字**不用括注**，写成平句（数据型括注如「前 69 / 后 76 dB」不在此限）。

## 简版一页构成（一页 A4，`scripts/build_simple.py`；正常测评报告次序）

- **次序定式**：页眉（标题 + 姓名/课题/录音/日期一行）→「六个维度」（左雷达 + 右总览）→「逐项解读」（两栏 × 三行）→「接下来怎么做」（小目标 + 在家练）→ 附全文 → 底部实景 + 页脚。亮点不做主视觉；先图后文、先总后分。
- **色彩分工**：奶白 #FFF9EA = 上部整幅色场（自页顶铺到逐项解读上方，下缘位置由内容算出、恒在「逐项解读」标题上方 34pt，波浪 + 两朵白云骑缝作区隔，分界不用横线）；黄 = 建筑（板框 #FFC93C、太阳 #FFD65A、便利贴）；绿 = 底部实景（双层浅绿山坡、树、灌木、草、带茎小花，与计分花同画法）；万寿菊橙 #ED8F24 = 雷达数据（线与 30% 填充）；红 = 只给挣来的小红花。
- **板框**：8pt 黄线，外缘离纸边 14pt（5 mm），整页色场和插画都收在框内；不做满版出血框（办公室打印机印不到纸边，会留一圈不均匀的白）。
- **太阳**：扁平圆盘（r 138）+ 药丸形光线（9 × 22，浮在盘边外 9pt，每 30° 一根），圆心藏在右上角外（W−30, H−16），#FFD65A。光线逐根判断：压到标题行 / 信息行 / 总览栏、被板框切断、或落在照片四周 14pt 内的不画；剩下的光线只在**三根相邻成组**时才画，凑不成组就一根不画——一根孤立的光线读作游离黄条。照片相纸（96 × 112，白边 + 轻投影 + 白胶带，转 2°）贴在太阳身上，照片 cover 裁切、主体完整。
- **雷达**：R 72，六轴同详细版六维；只画一组数据（橙线 + 30% 填充，顶点白芯橙点），网格五圈同为浅灰，外圈只略粗，不加阴影层；轴外**只写维度名**，按方位锚定（上下居中、右侧左对齐、左侧右对齐），满分顶点不压字。结论词不上图。不配读图说明。
- **总览**：位于照片下方的右栏，2–4 条「引导语：内容」，引导语加粗；每条 ≤ 两行，条间 4pt；不用术语、不写测量值、不与解读共用 7 字以上原句（脚本校验）。
- **逐项解读**：左栏内容三维、右栏声音三维，栏首各一行灰色小标题「说了什么 / 声音怎么样」；每格 = 维度名 + 结论词（黑字）+ 精修小红花（位置不变：格内 168pt 处）+ 1–3 行实测解读；两栏栏沟留足（右栏自 M+272 起，解读宽 222），**行高按该行两格中较长的解读计算**，不用固定行距。
- **接下来怎么做**：小目标 = 奶黄纸条 + 胶带；在家练三行 = 可勾选方框（11pt 圆角方框，三个游戏不分先后，不用序号）+ 游戏名 + 说明定列对齐。**小目标 / 在家练标题的基线必须与其首行内容同行**（标题归内容行，不许单独悬一行）。
- **文字压色块通则**：PDF 按基线定位而中文字形几乎全在基线之上，字面居中须把基线下压约 0.35em（徽章数字、纸条文字同此理），写成固定算法，不靠肉眼。
- **照片通则**：一律 cover 裁切（等比放大盖满、居中裁溢出部分），永不拉伸变形。
- **不设总体行**：无阶段、无一句话总评行（曾设过，已删）；更不许出现自创档位名或冒充官方等级的写法。
- **全文附录**：全文永不删减。框高按行数算，放不下时字号按 9.5 → 9 → 8.5 → 8 pt 逐级降（行距 1.45 倍，最后一级 8 pt / 1.36 倍），仍放不下才报错，精简的是解读或游戏。标题右侧一条浅灰录音波形 + 时长：时长标签右对齐在框内 12pt，波形宽度由标签宽度倒推（每 3pt 一根），任何时长（「45 秒」「1 分 48 秒」）都不出框；时长由 `audio_data.json` 算出，不手填。`mark` 里的练习词画红色虚线下划线，虚线在基线下 2.4pt，离下一行至少 2pt。
- **折行**：中文按词断行（jieba 可选，没有则逐字）；「嗯、啊」这类 ≤ 7 字的短引语、数字与单位（1.2 秒）整体不拆；句读与闭括号不落行首、开括号不落行尾；段末一行至少 3 个非标点字，英文段末一行至少两个词。
- **页脚**：一行「参照剑桥 Starters 与 IELTS 口语标准」（8pt），居中压在白色圆角小标签上，标签盖住其下的插画；不放「按录音实测」式方法说明；简版是独立一份，不写「另有详细版」。
- **实景**：底部双层山坡上大小树（大树带红果）、灌木、草叶、两朵带茎小花；全部程序矢量手画、哑光扁平、同一套画法，无 emoji、无高光塑料感。

## 全局禁用

- 左侧竖条 accent bar；装饰性横线/双线撑场；页脚「NAME · YEAR」；家长材料里的过程性用语；自造术语（统一用「点评」）。
