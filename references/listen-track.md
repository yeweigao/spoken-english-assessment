# 听评快速档（QwenWork 原生听音频路线）

## 定位与选档

- 与实测主流程（SKILL.md 第一～六步）并行的独立路线：结论全部来自 QwenWork 内置音频理解对录音的**两遍原生细听**，不出任何声学实测数据。适用：当天只要简版一页快速反馈，或本机没有识别模型（约 2.6 GB）/跑不了管线。
- 代价先讲清（选档时向家长方保密，对自己不保密）：① 录音**上云**处理，隐私敏感案例不选这条；② 云端模型升级后同一录音的听感结论会漂移，不可复现；③ 无词级计时，停顿只能给量级。要详细版两页、要内部依据文件、要可复现证据，回实测版。
- 两版产物**不混装**：听评材料零测量值、无「实测 / 声学」字样；实测材料不混听感措辞。量规、花数分档、成长阶段推导两版同一套（`rubric.md`），简版排版同一脚本。听评档**只出简版一页**。

## 第一步：素材与原文（同主流程规矩）

- 案例目录、`case.json`、任务类型 `task = speak | read` 的判定照 SKILL.md 第一步。朗读必须拿原文 `original` 与核心词 `focus`——自动纠正偏置在云端模型上同样存在（mule 读错时照样被听成 meal），只有对着原文才查得出读错的词。
- 视频先抽音轨：`ffmpeg -i input.mp4 -vn -c:a copy audio.m4a`，音频理解吃音轨比吃整段视频稳；照片另抽帧挑选（看镜头、睁眼、表情自然），cover 裁切进简版。
- 拿不到原文时先按录音内容搜教材 / 绘本名（第二遍的锚）；搜不到就用第一遍的「目标句还原」当工作原文，心里标注它不是逐字原文，报告里相应措辞降一级。

## 第二步：两遍听协议（核心工作法）

- **第一遍裸听转写**：逐句带时间标；**禁自动纠正**——孩子说错的词用近音拼写记实际听到的音，括注意图词；区分孩子与大人；标长停顿、重说、填充词（原生听音频能直接听到「嗯、啊」，这点比识别转写可靠）。
- **第二遍原文锚定**：把逐句目标文本与音轨一起送回，逐句核对五件事——① 逐词发音偏差（`focus` 核心词逐个过，再查词尾辅音、常混元音对，定位到元音或词尾）；② 流利度（停顿位置与归因：找词停顿多在内容词前；填充词与重说计数，零也要明记）；③ 语调（逐句句尾调型、重音落点）；④ 与原文差异（朗读查漏读 / 添读 / 换词，自创开场收尾算「自己的话」）；⑤ 可懂度（语境能懂 vs 单听会岔）。
- **防自动纠正三纪律**：原文在手逐词对照，专盯「说的和写的不一样」；同段换提示听两遍；发音结论只写「听到的是 Y」。

## 证据等级与措辞（红线）

- **零测量值**：秒数、语速、半音、次数不进任何家长材料——没有声学实测支撑的数字就是编造。停顿写「几处一秒上下的停顿」量级，不给精确秒。
- 听感只写「**像 X**」粒度，不写精确音标：两遍对同一个词可能给出不同听感（实测教训：mule 一遍像 meal、一遍像 mull），结论级一致就保留结论、丢弃听感分歧。
- 填充词措辞用听感口径「没有听到 um、啊」，不写声学口径的「无填充词」。
- 方法注 / 页脚不得出现「声音直接测量录音本身」类实测表述；`claims.md` 的「原生音频声学分析」卖点**不适用**听评产物，宣传材料引用前先核对口径。
- 能力边界（对内心里有数，不对家长展开）：云端依赖、不可离线、结论随模型版本漂移、无词级计时。

## 评分与排版

- 六维按 `rubric.md` 照常定档。声音三维**没有 `score_sound.py` 兜底**，是听评判断——每朵花必须配一句听感证据，3 朵及以下要具体到词；发音档证据是「听感对照」级，措辞相应降级。
- 排版同 `scripts/build_simple.py` + `case.json`（schema 与实测版完全一致，dims / goal / games / mark 由两遍听结果填写）。案例目录**不放** `audio_data.json`，波形自动省略——听评版天然无假波形。
- 全文永不删，字号自动降级；放不下时先精简总览 / 解读 / 游戏，精动的不是全文。渲图目检照主流程清单逐项过。

## 验收追加（听评档）

- 家长材料零测量值、无实测字样、无音标级断言。
- 全文与第二遍核对稿一致，不添不减；每个结论可回指一句原话或一次听感。
- 花数 / 印章 / 评语 / 雷达四处一致；`mark` 词三处对齐（全文、发音解读或小目标）。
- 参照案例：Apple《The Tiger by the Lake》听评档（2026-11-10，read 任务，108 秒视频）：两遍听抓到 magic e 系统性失效（lake 像 lack、mule 像 mull、cage 像 cadge），六维 5/4/5/3/4/4，绽放，只出简版一页。
