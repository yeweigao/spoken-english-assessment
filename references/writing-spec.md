# 老师说 · 英语学习小建议 —— 写作规范

<goal>
家长读完这两块，带走两样东西：
- 老师说：知道孩子的英语现在到了什么水平，并真心为孩子骄傲。这一块的作用是提供情绪价值。
- 英语学习小建议：知道接下来一段时间，在家能长期坚持做哪两三件事，让孩子往上走一步。
两块写的都是这个孩子的阶段水平，不是这一段视频。
</goal>

<reader>
幼儿园家长。多数不懂英语教学术语，会把报告转给家里人看。视频多半是他们自己拍的，视频里发生了什么，他们比老师更清楚。
</reader>

<material>
视频转写和六维逐项解读，是判断孩子阶段水平的证据。用它们判断孩子到了哪一步、强在哪、弱在哪、哪类音还没到位。写出来的是判断的结果，不是证据本身，证据已经在逐项解读里交代过了。

背唱的儿歌、朗读的绘本里的句子，孩子已经能背出来、读出来，这是他手里现成的英语。小建议可以帮孩子把这些句型用到真实生活里：比如儿歌里会唱问句，生活里就能用这个问句真的问一问。
</material>

<success>
老师说：
- 家长读完，能说出孩子现在到了什么水平、最值得骄傲的是哪一点。
- 换一个孩子就读不通，写的是这个孩子的能力组合。
- 读起来像一位熟悉孩子的老师在跟家长聊天。一批孩子放在一起读，每份的开头、节奏、切入点都不一样。

英语学习小建议：
- 小目标是一行字，写这个孩子从现在的水平往前迈一步要到达的能力。有重点音时用音名点到。
- 在家练三条都是家长能长期坚持的日常做法，写清楚什么时候做、做什么、孩子开口后家长怎么接。三条合起来，指向孩子最需要补的地方和重点音。
- 换一个水平不同的孩子，这三条就不适用了。
</success>

<constraints>
- 老师说只写肯定和鼓励。下一步怎么做、怎么练、发音部位怎么摆，都放在小建议里。
- 两块都不交代场景（看视频、今天、课上、现场），也不出现数字和花数。
- 小建议的场景和道具取自孩子的日常生活，比如饭桌、睡前、出门、绘本、玩具。不把视频原样再练一遍。
- 讲舌头、嘴唇怎么动时，照抄纠音表原话；例词用含这个音的常用词。
- 只练英语，不练唱歌和表演。
- 篇幅：老师说三到五句（便利贴最多六行）；小目标一行；游戏名五六个字。
</constraints>

<check>
写完对照 success 和 constraints 逐条自查，过不了就重写，不要只换几个近义词。一批做完跑 `python3 scripts/batch_check.py <批次目录>`。
</check>
