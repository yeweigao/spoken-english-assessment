# 范例：Toto《My Funny Face》（2026-11-09）

本目录只保留实测数据 `audio_data.json`（50 ms 峰值包络 + 基频序列）。

出于隐私，孩子的录音原件不随仓库分发；成品报告 PDF 为二进制文件，亦不在仓库内。
把 `audio_data.json` 放在案例目录、配合仓库根目录的字体运行 `scripts/build_front.py`
与 `scripts/build_back.py`，即可复现该报告（报告内容即两脚本中的案例段落）。
简版一页见 `scripts/build_simple.py` 中的 EXAMPLE_TOTO 数据块，运行时案例目录需有 `portrait.png`（按原话画的画像）。
